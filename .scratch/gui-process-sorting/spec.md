# GUI 进程列表三态排序

## 用户要求

GUI 的 CPU 和内存列支持排序：向上箭头表示占用从小到大，向下箭头表示从大到小，无箭头表示默认排序。

## 行为

- 启动时无箭头，默认沿用既有 CPU 占用从高到低排列。
- 重复点击同一列依次切换：降序（↓）→ 升序（↑）→ 默认（无箭头）。
- 切换另一列从降序开始，同一时间仅一列显示箭头；进程号和进程名列不切换排序。
- 相同占用按进程号从小到大排列，避免无意义的行顺序跳动。
- 后台先对全部可读进程排序，再截取前 64 项；升序采样选择实际占用最低的进程。
- 点击后立即重排已有读数，暂停或数据陈旧时也可切换；后续刷新保持所选顺序。
- TUI 保留原有 CPU／内存降序快捷键行为。

## 验证

排序比较器与 GUI 列点击测试覆盖两列三态切换、默认恢复、同值进程、超过 64 项、内存大整数、箭头互斥、暂停及刷新。

- `make test-tui`：终端指标及暂停缩放测试通过。
