## Agent skills

### Issue tracker

Track issues and specs as local Markdown files under `.scratch/<feature>/`. Before creating, fetching, or updating work items, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before assigning or changing a triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring domain concepts or proposing domain changes, read `docs/agents/domain.md`.
