# Triage 标签

各技能用五个规范 triage 角色来沟通。本文件把这些角色映射到本仓库 issue 跟踪器里实际使用的标签字符串。

| 技能中的角色 | 本仓库的标签 | 含义 |
| ------------ | ------------ | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可交给 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当某个技能提到某个角色（例如"打上 AFK-ready 的 triage 标签"）时，使用表格中对应的标签字符串。

以后要改标签命名，直接编辑右侧一列即可。
