# MacMonitor 1.1.0 改动与交付说明

发布日期：2026-10-06。版本号：1.1.0，构建号：2。

本次加入整机网络吞吐量和 CPU 温度，提供独立 GUI 卡片与终端读数，并为 GUI 进程表加入 CPU、内存三态排序。网络下载与上传读数字号为 16；TUI 仅显示这两项新增指标的实时读数，不显示它们的趋势。

## 逐文件改动

| 文件 | 改动及目的 |
| --- | --- |
| `src/network.c` | 使用系统 64 位接口字节计数与单调时钟计算速率，筛选联网实体接口，处理接口变化、计数回退和重新建立基线。 |
| `src/network.h` | 定义下载、上传速率、有效状态及采样器生命周期接口，统一状态和单位显示。 |
| `src/network_internal.h` | 提供接口过滤和计数差分的内部测试接口。 |
| `src/smc.c` | 解码温度数据，按明确来源回退选择 CPU 代表温度，并区分不可用与读取失败。 |
| `src/smc.h` | 定义温度读数、来源、状态和中文显示接口。 |
| `src/smc_internal.h` | 提供可替换读取器和解码测试接口，无需真实传感器即可验证错误路径。 |
| `src/core.c` | 在后台采集两项新增指标；恢复时立即采样、重建网络基线，并丢弃跨暂停／恢复边界的在途结果。 |
| `src/core.h` | 快照增加网络、温度、有效性、单调采样时间和恢复序号，供前端统一读取。 |

## 成品内容

- `MacMonitor.app`：macOS 12.0+，包含 x86_64 与 arm64，ad-hoc 签名。
- `macmon`：相同架构的独立 TUI 程序，可直接在终端执行。
- `使用说明.txt`、`更新日志.txt`：中文操作和版本记录。

成品保存在 [releases/1.1.0](../../releases/1.1.0/)，运行 `make release` 可重新生成。

## 验证与限制

核心测试 19 项、GUI 三态排序／新增指标／五种退出场景、TUI 真实伪终端测试均已通过。成品解压后已核对版本 1.1.0／构建 2、GUI 和 TUI 的两种架构、签名、执行权限、随包说明与 SHA-256；包内 TUI 的显示、CPU／内存排序快捷键和暂停缩放测试通过。

本机为 Intel MacBookAir8,2，已验证普通用户读取网络及 TC0E 虚拟 CPU 二极管温度。Apple M1～M5 的映射依据已注明的一手源码实现，尚无 Apple Silicon 实机验证；无法读取时显示明确状态。应用未经过 Apple 公证。
